# Highlights

- `p. 5` The evidence base is a late-2025 survey of more than 500 US technical leaders across company sizes and industries.
- `p. 8` Agent use is progressing from single tasks to process orchestration: 57% of respondents report multi-stage workflows and 16% cross-functional or end-to-end processes.
- `p. 11` A hybrid build strategy is most common: 47% combine packaged solutions with custom components, compared with 21% fully packaged and 20% fully custom approaches.
- `pp. 13–17` Research, reporting, data analysis, and internal process automation are prominent use cases; 80% of leaders report measurable economic impact from agents.
- `p. 20` The leading adoption barriers are integration with existing systems (46%), implementation cost (43%), and data access or quality (42%); smaller organizations report stronger people-side barriers.
- `pp. 21–22` Respondents say agents shift employee time toward strategy, relationships, and learning, while 81% plan more complex agent projects in 2026.
- `p. 26` Doctolib scaled coding agents with a shared repository of prompts, commands, and subagents, then embedded routine agent work into CI.
- `pp. 27–28` L'Oréal used an orchestrator plus specialized agents and reported 99.9% conversational-analytics accuracy across multiple data systems.
- `pp. 31–37` Regulated deployments emphasize adaptable workflows, human supervision, compliance controls, and evaluation against domain-specific or expert benchmarks.
- `p. 40` Resilient conversational agents need continuity across interruptions through capabilities such as resumability, redelivery, and preserved context.
- `pp. 41–42` External perspectives emphasize end-to-end workflow redesign, evolving quality controls, workforce reskilling, incentives, and sustained behavior change.
- `pp. 43–44` Anthropic's Economic Index analysis says enterprise usage favors full-task delegation, capability can matter more than token cost, and accessible context is a major bottleneck.
