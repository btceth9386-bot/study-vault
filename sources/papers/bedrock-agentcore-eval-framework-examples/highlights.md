# Highlights

- `p. 2160, Section: Supported agent frameworks` "What an agent emits as telemetry, and how that telemetry is structured, depends on the agent framework you build with and the instrumentation library you use to record it" — the premise that makes a framework-by-framework reference necessary in the first place.
- `p. 2166, Section: Strands Agents — How spans are identified` Strands classifies spans purely with `gen_ai.operation.name` (`invoke_agent`, `execute_tool`, `chat`) — the native OTel GenAI convention, with no OpenInference alternative offered for this framework.
- `p. 2202-2204, Section: OpenAI Agents — Instrument your agent` "AgentCore Evaluations supports both libraries. The libraries emit different scope names and use different span attributes. The evaluation service extracts the same values from each" — the explicit statement that dual-convention support is a designed feature, not an accident.
- `p. 2203, Section: OpenAI Agents — Instrument your agent` "When your agent runs with the AWS Distro for OpenTelemetry (ADOT)... you do not need to add explicit instrumentation code. Adding the instrumentation library to your project's dependencies is enough. ADOT discovers it at startup and activates it automatically" — repeated near-verbatim across every framework's setup instructions.
- `p. 2226, Section: Vercel AI SDK` The Vercel AI SDK is TypeScript-only; AgentCore Evaluations explicitly does not support a Python version, unlike the other frameworks which offer both languages.
- `p. 2248, Section: Google ADK — How spans are identified` Google ADK emits a nested span tree — an outer CHAIN span wraps an AGENT span, which wraps LLM and TOOL spans — with the outer CHAIN span (not the inner AGENT span) carrying the user prompt AgentCore treats as the invoke-agent content.
- `p. 2264, Section: Claude Agent SDK — How spans are identified` "The Claude Agent SDK emits only AGENT and TOOL spans; it does not emit separate inference (LLM) spans. The model metadata... and the agent response are carried on the AGENT span itself" — a concrete case of a framework collapsing the span taxonomy.
- `p. 2167, Section: Strands Agents — How evaluation fields are extracted` The distinction between split telemetry (content in a correlated event record) and unified telemetry (content as inline span events attached to the span) recurs, with identical wording, in every one of the seven framework sections — the identifying attribute stays on the span in both modes.
