# Highlights

- `pp. 5-7` AI accelerates code production but moves the bottleneck to human review, integration, and control; production work therefore needs more discipline than informal vibe coding.
- `pp. 7-10` A versioned specification serves as an architectural source of truth and combines technical design, rationale, visual aids, contracts, and behavioral scenarios.
- `pp. 11-12` Chat, repository specifications, reusable skills, and global or project instructions serve different lifetimes and scopes and should not be collapsed into one oversized prompt.
- `pp. 12-15` Project creation, feature work, bug diagnosis, documentation, and data engineering require different prompt modes and verification evidence.
- `pp. 15-18` MCP separates reusable tool exposure from individual agent frameworks through discoverable tool schemas and a standard client-server interaction.
- `pp. 18-20` High-volume AI changes require risk summaries, automated style enforcement, conditional integration gates, and explicit ownership rather than line-by-line human review of everything.
- `pp. 21-24` Continuous code review spans managed, hybrid, and custom runtimes; the appropriate tier depends on review specificity, cross-run memory, and failure impact.
- `pp. 24-25` Graph, vector, and exact-text retrieval can preserve both structural and semantic code relationships for large-scale impact analysis.
- `pp. 25-28` Approval fatigue weakens oversight, while external guardrails, isolated execution, and risk-based human checkpoints constrain autonomous actions.
- `pp. 29-32` Deterministic tests catch repeatable regressions, behavioral evaluations catch probabilistic drift, and hybrid policy gating combines structural permissions with semantic action review.
- `pp. 32-35` Context hygiene and runtime placeholder resolution reduce reliance on sensitive hardcoded values in prompts, tests, and tool arguments.
- `p. 36` The enduring human role is to specify intent, design controls, and integrate verified output while agents handle implementation detail.
