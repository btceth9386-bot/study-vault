This guide provides comprehensive instructions for contributing to the OpenTelemetry Semantic Conventions repository. It covers the entire contribution workflow, from setting up your environment to getting your pull request merged. For information about how to define new semantic conventions, see [How to Define New Conventions](#4.1).

## Purpose and Scope

The OpenTelemetry Semantic Conventions repository defines standardized attributes, metrics, and spans for telemetry data across various domains. This guide explains:

- How to set up your development environment
- The step-by-step process for contributing changes
- How to use the automation tools provided by the repository
- Special guidelines for different types of contributions

Sources: [CONTRIBUTING.md:1-7](), [README.md:7-9]()

## Prerequisites

Before you begin contributing, ensure you have:

1. Signed the [Contributor License Agreement (CLA)](https://identity.linuxfoundation.org/projects/cncf)
2. Installed the latest LTS release of Node.js
3. Installed the repository tooling packages
